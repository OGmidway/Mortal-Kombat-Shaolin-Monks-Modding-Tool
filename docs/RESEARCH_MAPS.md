- [Interactive Modding Progress](https://ogmidway.github.io/Mortal-Kombat-Shaolin-Monks-Modding-Tool/research/index.html): eight scoped feature checklists, each with six equally weighted milestones. Percentages describe these checklists only.
- [Interactive Engine Reconstruction](https://ogmidway.github.io/Mortal-Kombat-Shaolin-Monks-Modding-Tool/research/engine.html): nine engine systems. Coverage is unmeasured because complete inventories and defensible denominators do not exist yet.

The GitHub README displays static previews; hover/focus details run in the interactive pages. HTML files also work offline from the downloaded release guides.

Current SFD evidence includes eight source profiles, eight software-reviewed replacement samples, 97 packet checks, 59 synthetic allocation/write checks, six project persistence checks and four export checks. Builds compile for both channels. Full rebuilt-disc/game playback remains unverified.

Character/cutscene stretching and muted native-grunt regressions remain unresolved. Experimental distribution does not mark the validated-feature-shipped milestone complete. A 100% modding checklist would establish its named workflow, not full engine reconstruction or an automatic engine port. Reconstruction also requires portable implementations, reference parity and complete integrated regressions.

Evidence identifiers displayed by the maps reference maintainer research artifacts; they are not public download links. No game binaries or proprietary assets are included in these map files.
